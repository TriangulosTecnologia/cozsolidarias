## Key

- **Full-Evalued:** Always the "now"; regenerated each campaign; never edited by hand; production source of truth.
- **Runtime-Captured:** Immutable once written; result of a specific prompt; ephemeral (part of a round) but traceable (runId).
- **Golden corpus:** Subset of full-evalued that the agent can reach (~5 of the 23).
- **Delta:** The comparable structure of a spec, not the data rows (the agent never emits data).
- **Coverage gate:** Binary — if 1 R-* case fails, the variant is discarded before any scoring.

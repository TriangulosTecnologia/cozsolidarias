## title must name the variable, never the raw id:

Every `title` of `mapData`/`legends` is a readable phrase in pt-BR that names the
variable requested by the user (e.g., "Pessoas atendidas"), matching the `description`
of the catalogue field used to answer the "Variable" instruction above. Never use the
raw dataset/field id (e.g., `pessoasAtendidas`, `cozinhas_pessoas_atendidas`).
